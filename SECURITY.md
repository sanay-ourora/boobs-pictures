# Security policy

## Supported version

Security fixes are applied to the latest version on the `main` branch and the live site at [boobs.pictures](https://boobs.pictures).

## Reporting a vulnerability

Please use GitHub's [private vulnerability reporting form](https://github.com/sanay-ourora/boobs-pictures/security/advisories/new). Do not open a public issue for an unpatched vulnerability.

Include:

- A clear description of the issue and its potential impact
- Reproduction steps or a proof of concept
- Affected URLs, browsers, or commits
- Any suggested mitigation

You should receive an initial acknowledgement within seven days. Please allow time for a fix before publicly disclosing the issue.

## Scope

The current project is a static website. Hostinger account security, GitHub account security, third-party platforms, and social-engineering attacks are outside the repository's scope and should be reported directly to the relevant provider.
