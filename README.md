# boobs.pictures

A playful field guide and future community map for booby seabird sightings.

[Visit the live site](https://boobs.pictures)

## What is this?

`boobs.pictures` is becoming a community-powered atlas where people can share photographs and sightings of the world's booby seabirds. The current release is an interactive static landing page and design prototype.

Contributions are welcome. Please read [CONTRIBUTING.md](CONTRIBUTING.md) and our [Code of Conduct](CODE_OF_CONDUCT.md) before opening a pull request.

## Run locally

Serve the folder with any static server, for example:

```sh
npx serve .
```

## Deployment

The protected `main` branch is connected to Hostinger. After a pull request is merged, Hostinger automatically deploys that commit to the production website. Repository access, merge permissions, and the domain remain controlled by the maintainer.

See [DEPLOYMENT.md](DEPLOYMENT.md) for the release flow.
